# Auspify Technologies - Task 4: Employee Management System

A full-stack Employee Management System built as part of the Auspify Technologies Software Development Internship.

## Tech Stack
- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB (Mongoose)

## Features
- Employee Records (Add, Edit, Delete, View)
- Department Management & Filtering
- Search Employees (by name, email, position)
- Real-time Reports Dashboard (Total Employees, Total Payroll)

## How to Run

### Backend
```bash
cd backend
npm install
npm run dev
